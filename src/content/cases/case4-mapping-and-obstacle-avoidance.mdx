本实训不要求训练一个高精度检测模型。重点是打通“传感器—地图—障碍—速度指令”的链路，并能解释系统在什么情况下失效。

## 前置条件

- 完成第 4 章与第 3 章第 3 节。
- 能在仿真中控制机器人移动。
- 了解 ROS 2 话题、TF 与代价地图的基本概念。

## 步骤

1. **传感器接入**：确认激光雷达与深度相机的数据频率、坐标系与时间戳。
2. **建图**：在仿真场景中低速走一圈，保存点云与占据栅格地图。
3. **定位**：回到起点，比较估计位姿与真值，记录漂移。
4. **障碍检测**：用几何方法或轻量模型检测前方障碍，输出三维位置。
5. **接入规划**：把障碍写入局部代价地图，设置合理的膨胀半径。
6. **闭环测试**：设置 10 次带障碍的导航任务，统计成功率与碰撞次数。

## 预期结果

- 地图中的墙面、地面与障碍位置基本一致。
- 机器人能绕开静态障碍，且不会因膨胀过大堵死通道。
- 能给出端到端延迟与失败原因。

## 常见问题

| 现象 | 排查 |
| --- | --- |
| 地图重影 | 时间同步、外参、运动补偿、回环 |
| 定位跳变 | 特征不足、动态物体、TF 配置 |
| 障碍漏检 | 深度缺失、检测阈值、坐标系错误 |
| 机器人贴墙 | 膨胀半径、定位误差、控制误差 |
| 频繁停车 | 代价地图噪声、障碍误检、恢复行为 |

## 真机注意事项

FAST-LIVO2 的官方复现说明对硬件与同步有明确要求，包括 Lite3 Venture、AGX Orin、Ubuntu 22.04、ROS 2 Humble，以及硬件同步 / 软同步分支的选择。真机实验前务必逐项核对，不要在未确认同步的情况下直接运行。

> 安全提示：真机避障测试应设置低速、物理隔离与人工急停。首次测试不要使用动态障碍或人员作为目标。
