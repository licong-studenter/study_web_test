运动学不关心力和质量，只关心几何关系：关节转多少度，足端会到哪里？反过来，想让足端到达某个位置，关节应该转多少？这两个问题构成了四足机器人步态控制的地基。

本节先忽略髋关节外展，把一条腿简化成平面二连杆。这个简化模型足以解释绝大多数调试问题，也便于手算验证。

## 1. 坐标系与符号

定义单腿的基座坐标系：原点在髋关节，$x$ 轴指向机器人前方，$z$ 轴向上。设大腿长度 $l_1$，小腿长度 $l_2$，关节角 $\theta_1$ 与 $\theta_2$ 以图示方向为正。

足端位置可以写成：

$$ x = l_1 \sin\theta_1 + l_2 \sin(\theta_1+\theta_2) $$

$$ z = -l_1 \cos\theta_1 - l_2 \cos(\theta_1+\theta_2) $$

这就是正运动学（Forward Kinematics）。给定关节角，足端位置唯一确定。

## 2. 逆运动学

逆运动学（Inverse Kinematics）给定足端位置 $(x,z)$，求关节角。把两式平方相加：

$$ x^2 + z^2 = l_1^2 + l_2^2 + 2l_1l_2\cos\theta_2 $$

得到：

$$ \cos\theta_2 = \frac{x^2+z^2-l_1^2-l_2^2}{2l_1l_2} $$

再求 $\theta_1$：

$$ \theta_1 = \operatorname{atan2}(x,-z) - \operatorname{atan2}\left(l_2\sin\theta_2,\ l_1+l_2\cos\theta_2\right) $$

注意两个工程细节：

1. **工作空间**：当目标距离大于 $l_1+l_2$ 或小于 $|l_1-l_2|$ 时，解不存在。代码必须夹紧余弦值并报告不可达。
2. **多解**：平面二连杆通常有两组解（膝盖朝前或朝后）。四足机器人需要根据机械结构与避障需求选择固定分支。

一个最小 Python 实现：

```python
import math


def leg_ik(x: float, z: float, l1: float = 0.24, l2: float = 0.24):
    r2 = x * x + z * z
    cos_knee = (r2 - l1 * l1 - l2 * l2) / (2 * l1 * l2)
    if not -1.0 <= cos_knee <= 1.0:
        raise ValueError("target outside leg workspace")
    cos_knee = max(-1.0, min(1.0, cos_knee))
    knee = math.acos(cos_knee)
    hip = math.atan2(x, -z) - math.atan2(
        l2 * math.sin(knee),
        l1 + l2 * math.cos(knee),
    )
    return hip, knee
```

## 3. 雅可比矩阵

对正运动学求偏导，可以得到雅可比矩阵：

$$ \begin{bmatrix} \dot{x} \\ \dot{z} \end{bmatrix} = J(\theta) \begin{bmatrix} \dot{\theta}_1 \\ \dot{\theta}_2 \end{bmatrix} $$

雅可比描述了关节速度如何映射为足端速度。它在奇异位形附近会退化：某些方向的足端速度无法通过关节速度实现，逆解也可能数值不稳定。

根据虚功原理，足端力与关节力矩的关系为：

$$ \tau = J^T F $$

这条公式是后续 VMC 控制的核心。你不需要直接计算每个关节应该出多大力，而是先在任务空间设计足端力，再通过雅可比转置映射到关节。

## 4. 单关节与单腿验证

在 MuJoCo 中验证运动学时，建议分三步：

1. **固定身体**：只保留一条腿，给关节正弦指令，观察关节角跟踪。
2. **足端轨迹**：用逆运动学生成圆形或摆线轨迹，观察足端是否按预期运动。
3. **加入负载**：在足端施加力，观察关节力矩与跟踪误差。

评价指标包括：

- 足端位置误差（mm）。
- 关节跟踪误差（rad）。
- 速度与加速度是否平滑。
- 是否出现关节限位、速度饱和或数值跳变。

如果足端轨迹在仿真中抖动，先检查逆解分支是否切换、关节角是否跨越 $\pm\pi$、雅可比是否接近奇异。

## 5. 从单腿到整机

整机运动学还需要考虑：

- **髋外展关节**：让腿在侧向张开，影响横向稳定性。
- **身体位姿**：足端位置是相对身体的，身体在世界中的位姿由里程计或状态估计提供。
- **接触约束**：支撑足的足端速度应接近零，摆动足则可以自由运动。

步态控制通常先把身体目标转换为四个足端目标，再分别做逆运动学。足端目标必须满足工作空间、关节限位与碰撞约束，否则逆解会失败。

<Callout type="engineering">
逆运动学失败时，不要直接丢弃错误或返回零。应记录目标点、当前关节角与失败原因，并在控制器中进入安全降级状态。
</Callout>

## 6. 奇异位形与数值稳定性

雅可比矩阵在某些关节构型下会退化，这些构型称为奇异位形。对于平面二连杆，当腿完全伸直或完全折叠时，足端在某些方向上的速度无法由关节速度实现，逆解对目标位置的微小变化也会非常敏感。

工程上可以采取三类措施：

1. **限制工作空间**：在逆解前检查目标是否落在安全区域内，避免接近完全伸直。
2. **阻尼最小二乘**：在雅可比求逆时加入阻尼项，牺牲一点精度换取数值稳定。
3. **轨迹平滑**：避免足端目标在奇异点附近来回跳变，使用连续的速度与加速度约束。

一个常见的调试现象是：足端在某个位置附近突然抖动，关节角在两组解之间跳变。此时应先检查逆解分支与奇异位形，而不是盲目增大 PID 增益。

## 7. 足端轨迹生成

步态控制很少直接给一个固定足端位置，而是给一条随时间变化的轨迹。最简单的摆动相轨迹可以使用摆线：

$$ x(t) = x_0 + (x_1-x_0)\left(\frac{t}{T}-\frac{1}{2\pi}\sin\frac{2\pi t}{T}\right) $$

$$ z(t) = z_0 + h\sin\left(\pi\frac{t}{T}\right) $$

其中 $T$ 是摆动时间，$h$ 是抬腿高度。摆线的优点是起止速度为零，冲击较小；缺点是形状固定，遇到障碍时需要额外调整。

生成轨迹后，还要检查：

- 足端速度与加速度是否连续。
- 逆解是否始终存在。
- 关节速度是否超过上限。
- 足端是否与身体或障碍物碰撞。

这些检查可以在仿真中自动完成，也可以在控制器中做实时保护。把运动学约束前置到轨迹生成阶段，比在关节层反复限幅更可靠。

## 本节小结

- 正运动学由关节角计算足端位置，逆运动学相反。
- 平面二连杆的逆解需要处理工作空间与多解分支。
- 雅可比连接关节速度与足端速度，并通过 $J^T$ 把足端力映射为关节力矩。
- 单腿验证是整机步态调试的基础，应先确保足端轨迹平滑可控。
