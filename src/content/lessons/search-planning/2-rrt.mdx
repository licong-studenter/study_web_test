当机器人有七个关节时，构型空间是七维的。把每一维离散成 100 个格，节点数就是 $100^7$，图搜索几乎无法承受。采样规划换了一个思路：不枚举整个空间，而是用随机样本逐步探索可行区域。

## 1. RRT 的基本循环

快速扩展随机树（RRT）维护一棵从起点生长的树。每一轮：

1. 在构型空间中采样 $x_{rand}$。
2. 找到树中距离最近的节点 $x_{near}$。
3. 从 $x_{near}$ 朝 $x_{rand}$ 前进固定步长，得到 $x_{new}$。
4. 若边段无碰撞，把 $x_{new}$ 加入树。
5. 当新节点接近目标或与目标连通时结束。

伪代码：

```python
def rrt(start, goal, sample, steer, collision_free, max_iter=5000):
    tree = {start: None}
    for _ in range(max_iter):
        x_rand = sample()
        x_near = nearest(tree, x_rand)
        x_new = steer(x_near, x_rand)
        if collision_free(x_near, x_new):
            tree[x_new] = x_near
            if goal_reached(x_new, goal):
                return reconstruct(tree, x_new)
    return None
```

RRT 的概率完备性意味着：在足够多采样且存在可行路径时，找到路径的概率趋近于 1。它不保证路径最短，甚至可能绕很远，但对高维、复杂碰撞场景很有效。

## 2. 目标偏置与探索

纯随机采样会浪费大量样本在无关区域。常见改进是以概率 $p_{goal}$ 直接采样目标，其余时间采样整个空间：

$$ x_{rand}=\begin{cases}x_{goal}, & \text{以概率 }p_{goal}\\ \text{随机样本}, & \text{否则}\end{cases} $$

目标偏置提高收敛速度，但过大会让树陷入局部死胡同。工程上还会使用障碍物附近偏置、 informed sampling 与多树并行。

## 3. RRT* 为什么渐近最优

RRT* 在加入新节点后做两件事：

- **选择父节点**：在邻域内选择使路径代价最小的节点作为父节点。
- **重连**：若经过新节点能让邻域内已有节点获得更短路径，就改接它们的父节点。

代价定义为从起点沿树的累计路径长度：

$$ c(x_{new})=\min_{x\in N(x_{new})}\left(c(x)+\lVert x_{new}-x\rVert\right) $$

随着样本增加，RRT* 的路径代价依概率收敛到最优。这种"渐近"不是"几次迭代就最优"，实际运行往往需要大量样本和后处理 shortcut。

## 4. 碰撞检测决定真实速度

采样规划的瓶颈通常不是最近邻搜索，而是碰撞检测。机械臂需要在每个边段上检查连杆与环境的距离，四足机器人还要检查机身、腿部与地形。

实用技巧包括：

- 用包围盒或球体做粗筛，再做精确距离查询。
- 缓存碰撞结果，避免重复检查相同边段。
- 使用连续碰撞检测，防止快速运动穿过薄障碍。
- 在 KD-tree 中维护节点，加速最近邻查询。

<Callout type="concept">
RRT 的随机性不是缺陷，而是对高维空间的计算策略。它把"精确枚举所有可能性"换成"用有限样本覆盖重要区域"，代价是结果不稳定与需要概率性保证。
</Callout>

## 5. RRT、RRT* 与图搜索怎么选

| 方法 | 优势 | 局限 | 典型场景 |
| --- | --- | --- | --- |
| Dijkstra / A* | 最优性清晰、可解释 | 维度灾难、需要离散地图 | 二维导航、栅格地图 |
| RRT | 高维可行、实现直接 | 路径不最优、随机性大 | 机械臂快速规划 |
| RRT* | 渐近最优、可重连 | 样本需求大、实时性较弱 | 离线或准静态规划 |
| PRM | 多次查询复用路线图 | 建图成本高、动态环境弱 | 固定工作空间 |

在真实系统中，常见组合是先做全局 RRT 或 A*，再用轨迹优化平滑，最后由 MPC 跟踪。规划器给出拓扑可行的路线，控制器负责动力学可行性。

## 6. 让结果可复现

随机算法必须记录随机种子、采样范围、步长、碰撞容差与迭代上限。否则同一个场景的失败无法复现，也无法判断改动是否真的有效。

建议每次规划实验保存：成功率、平均规划时间、路径长度、最大关节速度、碰撞检测次数与失败原因。只看一张成功路径图，无法说明算法在边界场景下是否可靠。

## 本节小结

- RRT 通过随机采样与树扩展探索高维构型空间。
- 概率完备性不等于最优性，路径质量需要后处理。
- RRT* 通过选择父节点与重连获得渐近最优。
- 碰撞检测与最近邻查询是性能关键。
- 随机算法必须记录种子与统计指标，才能复现与评估。
