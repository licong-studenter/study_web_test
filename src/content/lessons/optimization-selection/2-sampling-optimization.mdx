有些目标函数没有可用的梯度：仿真器里有碰撞检测分支，控制器有饱和与模式切换，奖励函数由多次运行统计得到。此时梯度下降无法直接使用，采样优化提供了一条替代路径。

## 1. 黑箱问题的形状

把待优化参数写成向量 $\theta$，目标是：

$$ \min_\theta J(\theta) $$

我们只能调用 $J(\theta)$，看不到它的解析形式，也不一定有导数。机器人中的例子包括：

- 调整步态频率、抬腿高度与 PD 增益。
- 选择 MPC 权重与预测时域。
- 优化奖励函数系数。
- 调整视觉后端参数。

每次评估可能是一次仿真、一次真机试验，甚至是一整晚训练。样本预算往往比计算预算更昂贵。

## 2. 从随机搜索开始

最朴素的方法是在参数空间中随机采样，保留表现最好的样本：

$$ \theta^{(i)}\sim\mathcal N(\mu,\Sigma),\qquad \text{选择 }J(\theta^{(i)})\text{ 最小的若干个} $$

随机搜索在高维空间效率低，但它有一个重要优点：容易并行、容易加约束、失败不会导致整个流程崩溃。对于参数维度低、评估可并行的任务，它经常是可靠的基线。

## 3. 交叉熵方法与 CMA-ES

交叉熵方法（CEM）维护采样分布，每轮从精英样本重新估计均值与协方差。CMA-ES 进一步加入步长控制、协方差自适应与进化路径，能在非凸、病态问题上比朴素随机搜索更稳。

核心更新可以概括为：

1. 从当前分布采样一组候选。
2. 按目标值排序，选出精英。
3. 用精英更新均值。
4. 更新协方差与步长，使搜索分布适应地形。

协方差矩阵让算法学到参数之间的相关性。例如"抬腿高度增加时，步态频率也应降低"这种耦合，普通独立采样很难发现，CMA-ES 可以通过协方差逐渐捕捉。

## 4. 样本效率与维度

黑箱优化的样本复杂度通常随维度快速增长。十个参数可能需要数百次评估，五十个参数可能需要数万次。若每次评估要跑十分钟仿真，预算很快耗尽。

降低维度的方法包括：

- 先做敏感性分析，固定不敏感参数。
- 用低维参数化表示动作或增益曲线。
- 把物理约束写进参数边界，减少无效样本。
- 使用代理模型或多保真度仿真。

## 5. 过拟合仿真器

在仿真中调到最优的参数，可能在真机上失效。原因包括模型误差、执行器延迟、地面摩擦变化与传感器噪声。为避免"优化出一个只适合仿真器的控制器"，应：

- 在多个随机种子与地形上评估。
- 加入执行器噪声、延迟与负载扰动。
- 留出未参与优化的测试场景。
- 对参数变化做鲁棒性检查，而不是只看单点最优。

<Callout type="engineering">
优化器会充分利用你给的奖励。若奖励只鼓励前进速度，它可能学会拖地、跳跃或牺牲姿态。先设计能覆盖安全与舒适性的评估函数，再开始搜索。
</Callout>

## 6. 一个简单 CEM 实现

```python
import numpy as np

def cem(objective, mean, std, iterations=30, population=24, elite=6):
    for _ in range(iterations):
        samples = np.random.normal(mean, std, size=(population, len(mean)))
        scores = np.array([objective(x) for x in samples])
        chosen = samples[np.argsort(scores)[:elite]]
        mean = chosen.mean(axis=0)
        std = chosen.std(axis=0) + 1e-6
    return mean
```

真实实现还要处理参数边界、失败样本、并行评估与早停。若某组参数导致仿真崩溃，应给它一个明确的惩罚值，而不是让异常中断整个搜索。

## 7. 何时不用黑箱优化

若目标可微、约束清晰、维度较高，基于梯度的优化通常更高效。若问题有强物理结构，解析模型或 MPC 往往比黑箱搜索更可靠。黑箱优化适合"模型难写、评估可执行、维度不高"的场景。

## 本节小结

- 无导数优化适合梯度不可用或评估为黑箱的问题。
- CEM 与 CMA-ES 通过采样与精英更新适应目标地形。
- 样本复杂度随维度增长，降维与并行很重要。
- 仿真最优不等于真机可用，必须做多场景与鲁棒性评估。
- 奖励设计会直接决定优化器学到什么行为。
