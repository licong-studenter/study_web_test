Kalman 滤波假设后验是单个高斯峰。现实中的机器人定位经常不是这样：机器人可能站在看起来相同的两条走廊中，或在一段时间内完全失去观测。此时真正的后验有多个峰，用一个均值与协方差无法表达。粒子滤波用一组带权样本直接近似任意形状的分布。

## 1. 用样本近似后验

设粒子集合为：

$$ \left\{\left(x_t^{(i)},w_t^{(i)}\right)\right\}_{i=1}^{N},\qquad \sum_i w_t^{(i)}=1 $$

每个粒子是一个状态假设，权重表示它相对可信的程度。任何期望都可以近似为：

$$ \mathbb E[f(x_t)\mid z_{1:t}]\approx\sum_{i=1}^{N}w_t^{(i)}f\left(x_t^{(i)}\right) $$

粒子越多，近似通常越好，但计算量也越大。粒子滤波的优势是能表示多峰、非高斯与非线性，代价是采样误差与维度灾难。

## 2. 预测、加权与重采样

粒子滤波的循环非常直接：

1. **采样**：对每个粒子按运动模型采样 $x_t^{(i)}\sim p(x_t\mid x_{t-1}^{(i)},u_t)$。
2. **加权**：用观测似然更新 $w_t^{(i)}\propto w_{t-1}^{(i)}\,p(z_t\mid x_t^{(i)})$。
3. **归一化**：让所有权重之和为 1。
4. **重采样**：按权重复制高概率粒子，抑制低权重粒子。

这四步对应 Bayes 滤波的预测与更新，只是积分被 Monte Carlo 样本替代。

观测似然的形状决定粒子如何"收敛"。若激光雷达模型把每个观测点都当成独立高斯，错误匹配可能产生极端似然，导致少数粒子瞬间吞掉全部权重。工程上常对似然做平滑、截断或使用混合模型，以保留探索能力。

## 3. 重采样不是越多越好

重采样解决权重集中，但会引入样本贫化：高权重粒子被多次复制，低权重但可能正确的假设被永久删除。连续重采样还会让粒子过早塌缩到单一峰。

有效样本数（ESS）是常用诊断：

$$ N_{eff}=\frac{1}{\sum_{i=1}^{N}\left(w_t^{(i)}\right)^2} $$

当 $N_{eff}$ 远低于粒子数时才重采样，通常阈值取 $N/2$。若所有粒子权重相同，$N_{eff}=N$；若一个粒子独占权重，$N_{eff}\approx1$。

另一种改进是低方差重采样：用一条在 $[0,1]$ 上均匀分布的累计权重轴选择粒子，减少纯随机采样带来的方差。

## 4. 一个教学实现

```python
import numpy as np

def resample(particles, weights):
    positions = (np.random.random() + np.arange(len(particles))) / len(particles)
    cumulative = np.cumsum(weights)
    indexes = np.searchsorted(cumulative, positions)
    return particles[indexes]

def ess(weights):
    return 1.0 / np.sum(np.square(weights))
```

这段代码只展示低方差重采样的核心。真实系统中还要处理零权重、数值下溢、粒子边界与状态约束。权重建议在对数域累加后再归一化，避免长时间运行后全部变成 0。

## 5. 定位中的多峰与绑架问题

全局定位是粒子滤波最经典的应用。机器人不知道初始位置时，可以在整张地图上撒粒子。随着观测到来，与地图匹配的粒子权重上升，错误位置的粒子逐渐消失。

但粒子滤波也会遇到"被绑架"：机器人被突然搬到另一处，而所有粒子都集中在旧位置。由于新观测与旧假设完全不符，权重可能同时变得极小，滤波器无法恢复。解决办法包括：

- 持续注入少量全局随机粒子。
- 监测平均似然，长期过低时触发全局重定位。
- 使用自适应粒子数，在不确定性高时增加样本。

<Callout type="concept">
粒子滤波的"不确定性"不是一条协方差曲线，而是一群假设。看见粒子分成两团，往往比看见一个漂亮的高斯椭圆更有信息量：它提醒你，当前观测还不足以区分两种解释。
</Callout>

## 6. 何时不该用粒子滤波

粒子滤波适合低维、非线性、多峰的状态估计。若状态维度达到几十维，维持足够覆盖的粒子数会迅速爆炸。此时因子图优化、高斯滤波或学习式估计往往更合适。

在四足机器人上，粒子滤波常用于二维全局定位与多假设地形分类，而关节状态与 IMU 姿态更常用 EKF、误差状态滤波或优化。算法选型要看状态维度、后验形状与实时预算，而不是只看"粒子滤波更通用"。

## 本节小结

- 粒子滤波用带权样本近似任意后验分布。
- 预测、加权、归一化与重采样对应 Bayes 滤波的循环。
- 重采样必要，但过度重采样会造成样本贫化。
- ESS 是判断粒子退化的重要指标。
- 多峰定位与绑架恢复需要主动探索机制，不能只靠一次观测。
